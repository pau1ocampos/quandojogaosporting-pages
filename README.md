# Quando joga o Sporting?

Ever wondered when Sporting plays next? This is a small website that
answers exactly that.

👉 **https://quandojogaosporting.pt**

It shows:

- the next match, with a countdown to kick-off
- the upcoming matches and, when known, the TV channel
- Sporting's top scorers and assisters, in the league and in Europe
- the latest results
- the full Liga Portugal table, with Sporting highlighted

The site is in Portuguese, with an English version at `/en/`, and it
works just as well on a phone as on a computer.

## Where does this come from?

Don't edit anything here by hand. This repository only holds the
published site, and every file is generated automatically every six
hours from a separate repository and replaced in full. Any change
made here directly would be lost on the next update.

Match and table data come from the free tier of
[football-data.org](https://www.football-data.org/), shirt numbers
from Wikipedia and flags from
[flag-icons](https://github.com/lipis/flag-icons) (MIT, licence in
`flags/LICENSE`).

## Not official

This is a fan project. It has no connection whatsoever with Sporting
Clube de Portugal, and the lion in the icon is an original drawing,
not the club's crest.
